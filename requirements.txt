مهم:
- يجب أن يكون main.py هو ملف التطبيق الفعلي، وليس سكريبتًا ينشئ main.py داخل مسار خاص ببيئة أخرى.
- يجب أن يكون buildozer.spec بجوار main.py.
- لا يحتاج Buildozer إلى requirements.txt في هذا الإعداد؛ متطلبات التطبيق محددة في buildozer.spec.
- libraries.json هو قائمة أسماء مكتبات للبحث والعرض داخل التطبيق، ولا يعني أن هذه المكتبات مثبتة كلها أو أنها كلها متوافقة مع أندرويد.

2) محتوى buildozer.spec

[app]

3) ملف GitHub Actions

احفظ الملف التالي باسم:
.github/workflows/build.yml

----------------------------------------
name: Build Python Editor APK

on:
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-22.04

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      - name: Set up Java
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Install system dependencies
        run: |
          sudo apt-get update
          sudo apt-get install -y \
            git zip unzip autoconf libtool \
            pkg-config zlib1g-dev libncurses5-dev \
            libffi-dev libssl-dev cmake \
            libltdl-dev build-essential

      - name: Install Buildozer
        run: |
          python -m pip install --upgrade pip
          python -m pip install buildozer cython==0.29.36

      - name: Verify project files
        run: |
          pwd
          ls -la
          test -f main.py
          test -f buildozer.spec
          test -f libraries.json

      - name: Build APK
        run: buildozer android debug

      - name: Upload APK
        uses: actions/upload-artifact@v4
        with:
          name: pyeditor-apk
          path: bin/*.apk
          if-no-files-found: error
----------------------------------------

4) توليد libraries.json

من مجلد المشروع، شغّل:
python generate_libraries.py

سيُنشأ ملف libraries.json في المجلد الحالي. ارفع الملف إلى GitHub بجوار main.py.

5) ملاحظات مهمة على main.py

- تأكد أن main.py يحتوي على كود التطبيق الفعلي ويبدأ بالاستيرادات، مثل:
  import os, sys, json, threading, subprocess, keyword, builtins, urllib.request
- إذا كان الملف يحتوي على أسطر تنشئ main.py داخل /mnt/agents/output/pyeditor، فهذا سكريبت إنشاء وليس ملف التطبيق النهائي؛ لا تستخدمه كـ main.py النهائي دون مراجعة.
- يجب أن تكون المتغيرات مثل DEFAULT_CODE وlibs معرّفة قبل استخدامها.
- الطرفية داخل تطبيق أندرويد ليست بيئة Linux كاملة تلقائيًا، وأوامر shell وpip لن تعمل كما تعمل على الكمبيوتر أو Termux دون إعداد بيئة تنفيذ مناسبة.
- TensorFlow وPyTorch وغيرها من المكتبات الكبيرة لا يمكن ضمان تثبيتها داخل التطبيق بمجرد عرضها في قائمة المكتبات؛ التوافق مع Android/ARM وبنية الحزم يختلف.
- صلاحيات التخزين القديمة قد تختلف فعاليتها حسب إصدار Android. اختبر اختيار الملفات والحفظ على الهاتف المستهدف.

6) طريقة البناء

بعد رفع الملفات:
1. افتح GitHub ثم مستودع المشروع.
2. افتح تبويب Actions.
3. اختر Build Python Editor APK.
4. اضغط Run workflow، أو ادفع تحديثًا إلى فرع main.
5. عند نجاح المهمة، افتح التشغيل وابحث عن Artifacts.
6. نزّل pyeditor-apk واستخرج ملف APK ثم جرّب تثبيته على هاتفك.

7) إذا فشل البناء

افتح تفاصيل المهمة في Actions، وانسخ أول رسالة ERROR أو Traceback مع نحو 20 سطرًا قبلها. لا ترسل سطر exit code 1 وحده؛ فهو يوضح أن المهمة فشلت ولا يوضح السبب.
